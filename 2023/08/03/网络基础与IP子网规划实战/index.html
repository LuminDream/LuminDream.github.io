网络基础与 IP 子网规划实战

网络是运维一切排障的地基。报障电话里”上不了网””跨网段不通”的根因，80% 落在 IP 规划、掩码、网关这三件事上。这篇把网络基础与 IP 子网规划完整过一遍。

一、网络单位换算（先把这个算明白）

网络里最常见的”看起来很快”陷阱：

所以百兆网卡实际跑 12.5MB/s 是”满速”，不是网卡坏了。存储单位按 1024 进制（K/M/G/T），网络单位按 1000 进制，这个差异也是排障时对不上数的主要原因。

二、网络设备三个角色

  • 交换机（二层）：让同一网络内的多台主机互通。靠 MAC 地址寻址（网卡物理地址，全球唯一，16 进制）。早期靠广播发数据，广播太多会形成”广播风暴”——拆成多个小局域网（广播域）解决；
  • 路由器（三层）：实现不同局域网互通，隔离广播风暴。路由 = 数据跨网段到达目的地的传递过程；
  • 网关：去往其他网段的必经之路（路由器的 IP）。看路由表：

口诀记忆：交换机 = 认识的人（局域网内），路由器 = 朋友介绍的朋友（跨网段）。

三、分层模型：OSI 七层 vs TCP/IP 四层

OSI 七层（从下到上）：物理层 → 数据链路层 → 网络层 → 传输层 → 会话层 → 表示层 → 应用层。实际用的是 TCP/IP 四层（网络接口/网络/传输/应用）。

数据封装与解封装：

排障时”数据走到哪一层断了”是核心思路：物理层不通看网线/网卡，网络层不通看 IP/路由，传输层不通看端口，应用层不通看服务。

四、IP 地址与子网划分

分类与私有地址

IP = 网络号 + 主机号。公网地址全球唯一（Inter NIC 分配），私网地址组织内部使用可重复（RFC 1918）：

子网掩码与可用主机数

掩码的作用：区分网络号与主机号（网络位为 1，主机位为 0）。

子网划分（向主机位借位）

生产场景：运营商给了 116.63.0.10/29——实际可用 6 个 IP（网络地址 .9 之后的 6 个，网关一般用第一个可用）。

划分的意义：防止地址浪费、隔离广播域、降低网关负载。计算工具用 subnet 计算器，但面试和排障要能手算掩码和可用数。

VLSM / CIDR

  • VLSM：可变长子网掩码——大段里再细分小段（如 /24 拆 4 个 /26）；
  • CIDR：无类域间路由——/n 记法的来源，IP 段合并表达（如 10.0.8.0/24 表示整个网段）。
