🎓 教育背景

安徽工业大学 | 计算机科学与技术学院 | 物联网工程（本科） | 2019.09 — 2023.06

⚙️ 技能栈

Linux 系统与基础服务

Linux 系统 熟练掌握 CentOS / Ubuntu / Debian / Rocky Linux 等主流发行版，熟悉系统启动流程、Systemd 服务管理、用户权限模型、磁盘与 LVM 管理，具备独立排查系统级故障的能力。
Shell 脚本 能编写脚本实现日志切割、批量部署、定时备份、自动巡检等自动化任务，熟练使用 awk / sed / grep 进行日志分析。
Web 服务 熟练部署与调优 Nginx（反向代理、负载均衡、SSL 证书、动静分离）、Tomcat、OpenResty，具备高可用架构搭建经验。

容器与编排

Docker 熟练进行应用容器化封装、镜像构建与优化（多阶段构建、分层缓存）、Docker Compose 编排，熟悉网络模型（bridge / host / overlay）与数据卷管理。
Kubernetes 具备集群搭建（kubeadm / 二进制）、日常运维与故障排查能力，熟悉 Pod / Deployment / Service / Ingress / ConfigMap / PV/PVC 等核心资源，了解 RBAC、HPA 自动伸缩、节点调度策略。
Helm 能使用 Helm 进行 K8s 应用的包管理与版本化部署，具备自定义 Chart 编写能力。

自动化运维与 CI/CD

Ansible 熟练编写 Playbook 实现批量配置管理与应用部署，熟悉 Inventory 管理、Roles 编排、Jinja2 模板，能设计可复用的自动化方案。
Jenkins 具备 Pipeline 流水线搭建能力，实现代码拉取、编译构建、镜像打包、自动部署的全流程 CI/CD。
GitLab CI 熟悉 .gitlab-ci.yml 配置，能设计多阶段流水线，结合 Runner 实现自动化构建与部署。

监控告警与日志

Zabbix 熟练搭建与维护监控平台，能自定义模板、触发器与告警动作，熟悉 Agent / SNMP / IPMI 等多种采集方式。
Prometheus 熟悉 Prometheus + Grafana 体系，能配置 ServiceMonitor、自定义 Exporter、AlertManager 告警规则，擅长设计可视化 Dashboard。
ELK Stack 具备 Elasticsearch + Logstash/Fluentd + Kibana 日志平台搭建经验，熟悉日志采集、过滤、索引与 ILM 生命周期管理。

网络与安全

网络基础 扎实的 TCP/IP 基础，熟悉 DNS / DHCP / HTTP(S) / SSH / VPN 等协议，能使用 tcpdump / Wireshark 进行抓包与故障定位。
安全加固 具备服务器安全加固经验：SSH 加固、fail2ban、防火墙配置（iptables / firewalld）、SELinux 策略、漏洞扫描与修复。

数据库与中间件

MySQL 具备安装部署、主从复制、读写分离、备份恢复（mysqldump / xtrabackup）能力，熟悉慢查询分析与性能调优。
Redis 熟悉持久化策略（RDB / AOF）、主从哨兵、Cluster 集群模式，能进行内存管理与调优。
其他 了解 MongoDB、Kafka、RabbitMQ 等中间件的基础运维与常见故障处理。

云平台与虚拟化

公有云 具备阿里云 / 腾讯云运维经验，熟悉 ECS、RDS、SLB、OSS、VPC、安全组等核心产品，了解云监控与费用优化。
虚拟化 了解 VMware vSphere / KVM 虚拟化平台，具备虚拟机生命周期管理与资源分配经验。
